# Anestezi Kitaplık Merkezi

Beş takip listesini tek ana ekrandan açan, mobil uyumlu bir HTML sistemi.

## Dosyalar
- `index.html`: ana kontrol paneli
- `modul-takip.html`: anestezi eğitim modülleri
- `miller-takip.html`: Miller Anestezi
- `marino-takip.html`: Marino Yoğun Bakım
- `lange-takip.html`: Lange Anestezi
- `rejyonel-blok-takip.html`: Rejyonel Bloklar
- `assets/logo.svg` ve `assets/icon.svg`: uygulama logosu ve simgesi

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Kayıtlar
İşaretler tarayıcının yerel `localStorage` alanında saklanır; otomatik olarak farklı cihazlara senkronize olmaz.
